# Hostel Day Hub 2026 🎉

An interactive web portal for students to submit anonymous suggestions, vote on food preferences, and check event schedules for Hostel Day celebrations.

## Features
- **Anonymous Suggestions**: Submit event ideas safely with real-time upvoting.
- **Food Preference Poll**: Interactive voting on grand dinner menu items.
- **Event Schedule**: Timeline of cultural programs and competitions.
- **Supabase Integration**: Real-time database back-end for votes and suggestion storage.
